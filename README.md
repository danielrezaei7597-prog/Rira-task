# Rira-task

# اپلیکیشن تبدیل ارز (دلار ↔ ریال)

یه برنامه ساده برای تبدیل دلار به ریال (و برعکس) با نرخ لحظه‌ای. هم توی مرورگر کار می‌کنه، هم به صورت یه فایل `.exe` روی ویندوز.

---

## چی داره؟

- نرخ لحظه‌ای دلار از یه API رایگان و بصورت ثبت نام رایگان این API تهیه گردید
- جدول نرخ لحظه ای دلار و تغییرات قیمت در 24 گذشته بصورت درصد و تومان .
- تبدیل دوطرفه با یه input و یه select ساده
- پیغام خطا وقتی اینترنت قطعه + دکمه «چک مجدد»
- تم روشن و تاریک
- خروجی `.exe` برای ویندوز با آیکون اختصاصی

---

## چطور ساختم؟


### ۱. سند PRD

قبل ازهرچیز این تسک قرار بود تنها کار تبدیل دلار به ریال و بالعکس رو انجام بده ولی از دید یک متخصص طراح مخصول به تسک نگاه کردم و تصمیم گرفتم ویژگی هایی به مخصول اضافه کنم از جمله اینکه با یک API بصورت هر 30 ثانیه قیمت لخظه ای دلار رو بخونه و در یک جدول بهمراه تغییرات 24 گذشته نمایش بده و با تگ های select , input قابلیت انتخاب ریال یا دلار رو فراهم کردم و اگر هم اینترنت قطع شد یک پیغام خطا و دکمه رفرش برنامه ظاهر بشه و با زدن رفرش دویاره این  یه سند PRD نوشتم (حدود ۲۰۰ خط) که مشخصات دقیق برنامه رو توضیح می‌داد — چه ویژگی‌هایی باشه
### ۲. UI Kit

بر اساس PRD، یه UI Kit درستنگی، اندازه فونت‌ها، و استایل کامپوننت‌ها تا کدنویسی منسجم‌تر باشه.

### ۳. HTML

ساختار صفحه رو با تگ‌های semantic HTML5 دستی نوشتم. تصاویر بکگراند تم‌ها با هوش مصنوعی ساخته شدن.

### ۴. CSS

استایل‌دهی با CSS خالص (بدون فریمورک). آیکون‌ها از Font Awesome.

### ۵. TypeScript

منطق برنامه رو با TypeScript نوشتم — فراخوانی API، به‌روزرسانی خودکار، مدیریت خطا، و رویدادها.

### ۶. کامپایل

با نصب Node.js و `tsc`، فایل `.ts` رو به JavaScript کامپایل کردم.

### ۷. بسته‌بندی با Electron

برای داشتن یه فایل اجرایی مستقل، از Electron استفاده کردم. خروجی نهایی یه فایل `.exe` حدود ۹۳ مگابایته.

## نصب و اجرا
```bash
# نصب پکیج‌ها
npm install

# کامپایل TypeScript
tsc

# ساخت فایل exe
npm run build

نسخه آماده در بخش **Releases** به صورت پارت‌های ۲۰ مگابایتی قرار داره.

## یه نکته

تمام کدها رو خودم خط به خط نوشتم. از هوش مصنوعی فقط برای پیدا کردن سینتکس توابع یا دیباگ استفاده کردم. — نه برای تولید کد. کامنت‌گذاری داخل فایل‌ها و نحوه نوشتن کد این موضوع رو تایید میکنه .
- عکس های بک گراند تم دارک و لایت و عکس آیکون فایل .exe با هوش مصنوعی تولید شده است .
