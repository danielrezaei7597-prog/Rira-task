# Rira-task

# اپلیکیشن تبدیل ارز (دلار ↔ ریال)

یه برنامه ساده برای تبدیل دلار به ریال (و برعکس) با نرخ لحظه‌ای. هم توی مرورگر کار می‌کنه، هم به صورت یه فایل `.exe` روی ویندوز.

---

## چی داره؟

- نرخ لحظه‌ای دلار از یه API رایگان (هر ۳۰ ثانیه بهگان (هر ۳۰ ثانیه به‌روز می‌شه)
- جدول تغییرات  درصد)
- تبدیل دوطرفه با یه input و یه select ساده
- پیغام خطا وقتی اینترنت قطعه + دکمه «چک مجدد»
- تم روشن و تاریک
- خروجی `.exe` برای ویندوز با آیکون اختصاصی

---

## چطور ساختم؟

### ۱. سند PRD

قبل از هر چیز یه سند PRD نوشتم (حدود ۲۰۰ خط) که مشخصات دقیق برنامه رو توضیح می‌داد — چه ویژگی‌هایی باشه، چه خطاهایی رو هندل کهایی رو هندل کنه، UI چطور باشه.

### ۲. UI Kit

بر اساس PRD، یه UI Kit درستنگی، اندازه فونت‌ها، و استایل کامپوننت‌ها تا کدنویسی منسجم‌تر باشه.

### ۳. HTML

ساختار صفحه رو با تگ‌های semantic HTML5 دستی نوشتم. تصاویر بکگراند تم‌ها با هوش مصنوعی ساخته شدن.

### ۴. CSS

استایل‌دهی با CSS خالص (بدون فریمورک). آیکون‌ها از Font Awesome.

### ۵. TypeScript

منطق برنامه رو با TypeScript نوشتم — فراخوانی API، به‌روزرسانی خودکار، مدیریت خطا، و رویدادها.

### ۶. کامپایل

با نصب Node.js و `tsc`، فایل `.ts` رو به JavaScript کامپایل کردم.

### ۷. بسته‌بندی با Electron

برای داشتن یه فایل اجرایی مستقل، از Electron استفاده کردم. خروجی نهایی یه فایل `.exe` حدود ۹۳ مگابایته.

---

## نصب و اجرا
```bash
# نصب پکیج‌ها
npm install

# کامپایل TypeScript
tsc

# ساخت فایل exe
npm run build

نسخه آماده در بخش **Releases** به صورت پارت‌های ۲۰ مگابایتی قرار داره.

## یه نکته

تمام کدها رو خودم خط به خط نوشتم. از هوش مصنوعی فقط برای پیدا کردن سینتکس توابع یا دیباگ استفاده کردم — نه برای تولید کد. کامنت‌گذاری داخل فایل‌ها هم این رو نشون می‌ده.
