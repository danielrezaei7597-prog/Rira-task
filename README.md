# Rira-task

# اپلیکیشن تبدیل ارز (دلار ↔ ریال)

یه برنامه ساده برای تبدیل دلار به ریال (و برعکس) با نرخ لحظه‌ای. هم توی مرورگر کار می‌کنه، هم به صورت یه فایل `.exe` روی ویندوز.

---

## چی داره؟

- نرخ لحظه‌ای دلار از یه API رایگان و بصورت ثبت نام رایگان این API تهیه گردید
- جدول نرخ لحظه ای دلار و تغییرات قیمت در 24 گذشته بصورت درصد و تومان .
- تبدیل دوطرفه با یه input و یه select ساده
- پیغام خطا وقتی اینترنت قطعه + دکمه «چک مجدد»
- تم روشن و تاریک
- خروجی `.exe` برای ویندوز با آیکون اختصاصی

---

## چطور ساختم؟


### ۱. سند PRD

قبل ازهرچیز این تسک قرار بود تنها کار تبدیل دلار به ریال و بالعکس رو انجام بده ولی از دید یک متخصص طراح مخصول به تسک نگاه کردم و تصمیم گرفتم ویژگی هایی به مخصول اضافه کنم از جمله اینکه با یک API بصورت هر 30 ثانیه قیمت لخظه ای دلار رو بخونه و در یک جدول بهمراه تغییرات 24 گذشته نمایش بده و با تگ های select , input قابلیت انتخاب ریال یا دلار رو فراهم کردم و اگر هم اینترنت قطع شد یک پیغام خطا و دکمه رفرش برنامه ظاهر بشه و با زدن رفرش دویاره وصل شدن اینترنت رو چک می کنه و تا اینترنت متصل نشه برنامه به کار خودش ادامه نمیده ؛ برای تمامی موارد گفته  شده  یک سند PRD تهیه گردید (حدود ۲۰۰ خط در قالب فایل .md) که مشخصات دقیق برنامه رو توضیح می‌داد — چه ویژگی‌هایی باشه و این سند رو با مدل زیانی ChatGPT تنظیم گردید که با شرح کامل مراحل و گزینه های محصول و تخصص مورد نیاز برای این حوزه ، این سند در قالب فایل markdown تهیه گردید .
### ۲. UI Kit

بر اساس سند PR با هوش مصنوعی  Clade sonnet5 سند PRD الصاق به مدل گردید و با شرح دقیق ویژگی های مورد نیاز UI از جمه ترکیب رنگی یا همون palette color و شرح دقیق نیازمندی فونت ها ، فاصله گذاری ها تمامی دکمه ، لحن برند ؛ یک UI KIT جامع تهیه گردید و خروجی بصورت فایل .html تنظیم شد .

### ۳. HTML

در مرحله بعدی فایل html بصورت دستی و رعایت semantic بودن تگ ها توسط من نوشته شد سپس برای هر قسمت و تگ کامنت گذاری لازم رعایت گردید .
### ۴. CSS

استایل‌دهی با CSS خالص در قالب یک فایل .css بصورت جدا و کاملا دستی با رعایت ریسپانسیو بودن برای دستگاه های مختلف و کامنت گذاری هر بخش صفحه ، گرچه امکان استفاده از tailwind هم وجود داره ولی ازونجایی که تسک بسیار کوچک و با هدف ارزیابی تعریف شده تماما بصورت دستی و css خالص تهیه گردید برای فونت مریوط به آیکون ها نیز از کتابخونه آنلاین font awesome استفاده شده است.

### ۵. TypeScript

منطق برنامه در قالب فایل typescript با پسوند .ts بصورت دستی با کامنت گذاری برای قسمت تهیه گردید تا اتصال هر 30 ثانیه به API صورت گیرد و در صورت دیکانکت شدن اینترنت پیغام و سکشن رفرش صفحه ظاهر شود همچنین با کلیک روی تگ هایی که باید کلیک شوند و عملیات مربوطه صورت بگیرد event و تابع تنظیم گردید .

### ۶. کامپایل

در مرحله بعد با نصب Node.js پکیج npm نیز همراه آن نصب گردید که در ترمینال vs code امکان نصب کامپایلر typescript یعنی tsc فراهم گردید که با انجام اینکار فایل .ts کامپایل شده و خروجی JavaScript مورد نظر تولید گردید ؛ در این بخش برنامه تکمیل گردید و هر 3 فایل .js , .css , .html به همراه دو تا فایل عکس بک گراند کنار یکدیگر قرار داده شدند .
### ۷. بسته‌بندی با Electron

چون هدف این برنامه تهیه یک فایل اپلیکیشن نهایی بود تصمیم گرفتم برای نسخه دسکتاپ ویندوز یک فایل نهایی .exe تهیه کنم ، به این ترتیب سراغ فریمورک react رفتم و اونجا با تحقیقات متوجه شدم با electron امکان تبدیل هر 3 فایل به یک فایل اجرایی وجود خواهد داشت ؛ پس در نهایت یک فایل اجرایی .exe همراه آیکونی مناسب تهیه کردم که حجم آن حدود 93 مگابایت شد و برای کامیت روی github در قالب فایل .rar و با تقسیم به پارت های 20 مگابایتی آپلود کردم .
